# 📋 个人计划执行工作台

一个纯前端、零依赖、单页应用式的个人「计划 — 执行 — 复盘」工作台。全部数据保存在**本机浏览器**（localStorage），支持一键备份 / 恢复，可直接部署到 GitHub Pages。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 🔐 登录页 | 账号密码登录（默认 `Frank` / `Stzj123`），支持"记住我"免登录、修改密码 |
| 📊 总览 | 今日计划、今日例行、本周例行、逾期提醒、近 7 天完成率、目标速览、最近随记 |
| 🧭 形势分析 | 工作 / 生活（身体、情绪、其他）/ 人际三个板块，全部内容可编辑、可增删分组 |
| 🎯 目标与问题 | 按重要性标星（1~5★），支持子目标勾选与进度条；每个目标可记录「解决方案与措施」 |
| ✅ 事项安排 | 工作 / 生活 / 学习三类：例行事务按 **每日 / 每周（周六起算）** / 每月 自动重置；待办任务可设截止日（自动算逾期与倒计时）；每条事项可勾选完成、撰写执行总结 |
| 📅 每日计划 | 工作日按「工作 / 中午 / 晚上」三板块，周末合并为全天；支持"带入昨日未完成"、每日小结 |
| 📝 随记总结 | 像便笺一样随时记录，**自动提取关键词**，关键词云筛选；顶栏「✏️ 随记」任何页面随手记 |
| 🧰 工具箱 | JSON 备份导出 / 导入、恢复初始数据、修改密码、**一键周报**（周六→周五）、功能说明 |

### 附加实用功能
- ⏱️ 番茄钟（专注 25 / 深度 45 / 休息 5，结束提示音）
- 🌙 深色模式（侧栏底部切换）
- 🔍 全局搜索（侧栏底部，覆盖事项 / 目标 / 分析 / 随记 / 每日计划）
- ⏰ 截止日倒计时与逾期高亮，侧栏导航角标提示
- 📈 近 7 天计划完成率柱状图
- 📱 移动端自适应布局
- ⌨️ 快捷键：`Ctrl+Enter` 保存随记 · `Esc` 关闭弹窗 · 输入框内 `Enter` 快速添加

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可；或启动一个静态服务器：

```bash
cd personal-workbench
python -m http.server 8000
# 或 npx serve .
```

访问 http://localhost:8000 ，使用默认账号 `Frank` / 密码 `Stzj123` 登录。

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "feat: 个人计划执行总结工作台"
git remote add origin https://github.com/<你的用户名>/personal-workbench.git
git push -u origin main
# 然后在 GitHub 仓库 Settings → Pages → Source 选择 main 分支 / root 目录
```

之后即可通过 `https://<你的用户名>.github.io/personal-workbench/` 访问。

## 数据与安全说明

- 所有内容仅存储在当前浏览器的 localStorage 中：**换浏览器 / 换电脑 / 清理缓存前，请先在「工具箱」导出备份**。
- 登录为纯前端校验（凭据经混淆存储在前端代码中），仅起隐私屏风作用，**不是安全边界**；请勿使用重要密码。若需真正的访问控制，可部署在带鉴权的内网环境。
- 「工具箱 → 恢复初始数据」会清空当前全部内容，操作前请确认已备份。
