# 📋 个人计划执行工作台

一个纯前端、零依赖、单页应用式的个人「计划 — 执行 — 复盘」工作台。全部数据保存在**本机浏览器**（localStorage），支持一键备份 / 恢复，可直接部署到 GitHub Pages。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 🔐 登录页 | 「访问令牌 + 账号密码」双重门禁：本设备需先粘贴 GitHub 访问令牌，再用账号密码登录；密码以加盐 SHA-256 哈希存放在私人数据仓库，公开代码中不含任何密码 |
| ☁️ 云同步 | 数据可存到 GitHub：推送到/恢复自你名下的**私人数据仓库**（public 代码仓库中无任何数据）；新设备凭令牌登录后自动接续 |
| 📊 总览 | 今日计划、今日例行、本周例行、逾期提醒、近 7 天完成率、目标速览、最近随记 |
| 🧭 形势分析 | 工作 / 生活（身体、情绪、其他）/ 人际三个板块，全部内容可编辑、可增删分组 |
| 🎯 目标与问题 | 列表概览 + 点击进入**专属详情页**：编辑重要度（1~5★）、**解决方案与措施**、子目标勾选与进度条 |
| ✅ 事项安排 | 工作 / 生活 / 学习三类：例行事务按 **每日 / 每周（周六起算）** / 每月 自动重置；待办任务可设截止日（自动算逾期与倒计时）；每条事项可勾选完成、撰写执行总结 |
| 📅 每日计划 | 工作日按「工作 / 中午 / 晚上」三板块，周末合并为全天；支持"带入昨日未完成"、每日小结 |
| 📝 随记总结 | 像便笺一样随时记录，**自动提取关键词**，关键词云筛选；顶栏「✏️ 随记」任何页面随手记 |
| 🧰 工具箱 | JSON 备份导出 / 导入、恢复初始数据、修改密码、**一键周报**（周六→周五）、功能说明 |

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可；或启动一个静态服务器：

```bash
cd personal-workbench
python -m http.server 8000
# 或 npx serve .
```

访问 http://localhost:8000 ，按页面提示粘贴 GitHub 访问令牌并设置账号密码即可使用。

## 云同步与登录机制

- **登录**：本设备首次使用需粘贴 GitHub 访问令牌（PAT，仅存本机浏览器），随后设置账号密码。密码以「随机盐 + SHA-256」哈希后保存到私人数据仓库 `personal-workbench-data` 的 `auth.json`，网站代码里不含任何密码，他人无法从公开代码或公开页面获取。
- **数据**：全部数据保存为一个 JSON（`data.json`），提交到你名下的私人仓库 `personal-workbench-data`。工具箱里可随时「推送到 GitHub」/「从 GitHub 恢复」；换设备登录后若本地无数据会自动拉取。
- **创建令牌**：GitHub → Settings → Developer settings → Personal access tokens。推荐经典令牌勾选 `repo` 权限；Fine-grained 令牌则需授权 `personal-workbench-data` 仓库 + Contents: Read and write。
- **吊销/退出**：令牌可随时在 GitHub 设置中吊销；工作台「工具箱 → 移除本机访问令牌」可清除本机授权。

## 安装为手机 App（PWA）

无需打包：安卓手机 Chrome（或其他 Chromium 内核浏览器）打开网站 → 菜单 → **「安装应用 / 添加到主屏幕」**，桌面即出现独立图标，打开为全屏应用；已配置 Service Worker，支持离线打开已缓存的界面。iPhone Safari 用「分享 → 添加到主屏幕」。数据照常使用令牌登录 + 云同步。

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "feat: 个人计划执行总结工作台"
git remote add origin https://github.com/<你的用户名>/personal-workbench.git
git push -u origin main
# 然后在 GitHub 仓库 Settings → Pages → Source 选择 main 分支 / root 目录
```

之后即可通过 `https://<你的用户名>.github.io/personal-workbench/` 访问。

> **私人仓库注意**：GitHub 免费计划不支持为私人仓库开启 Pages（升级 Pro 可用）。私人仓库仅作代码备份时，本地直接双击 `index.html` 或运行静态服务器即可使用本应用；若希望获得在线网址且保持免费，需将仓库设为 Public。

## 数据与安全说明

- 本机数据保存在浏览器 localStorage；云端数据保存在你名下的**私人仓库**，公开的网站代码仓库里不含任何数据。
- **公开网站 + 双重门禁**：其他人打开网站只能看到「访问令牌」输入页——没有你的令牌，既看不到登录界面背后的内容，也无法读取你私人仓库里的任何数据。
- 登录为纯前端校验，配合令牌门禁满足个人使用；请勿把工作台密码设为你其他重要账户的密码。
- 「工具箱 → 恢复初始数据」会清空当前本机全部内容，操作前请确认已备份/推送。
